📌 伪类选择器（:）—— 选中特定位置 / 状态

  • 第1项（:first-child → 红色加粗）
  • 第2项
  • 第3项（:nth-child(3) → 背景绿色）
  • 第4项
  • 第5项（:last-child → 蓝色斜体）

观察：第1项红加粗，第3项绿背景，第5项蓝斜体； 除了 class="special" 的第3项外，其他都带有虚线底边（:not 效果）。

📌 伪元素选择器（::）—— 生成虚拟内容

我是一个普通的 div，但前后被插入了 “【开始】” 和 “【结束】” （通过 ::before 和 ::after）

这是一句引文，前后被插入了双引号（通过 ::before 和 ::after）

注意： 伪元素必须设置 content 属性才能显示， 且它们在 DOM 中看不见，但在浏览器 F12 的 Elements 面板中能看到 ::before / ::after 的虚拟节点。
